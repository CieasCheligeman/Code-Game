# Dew Point · Code Game

A story game that teaches you to read four real C++ dew-point programs, set in a rain-drowned Tokyo. Misread the code and the sea rises; read it well and the sky clears.

- **Play:** open `index.html` in a browser. Choose **3D Tokyo** or **Classic 2D** on the title screen.
- **Answer key:** [`ANSWERS.md`](ANSWERS.md) has every answer, plus URL shortcuts for jumping straight to the scenes.
- **The programs:** `project#1.cpp`, `project#2.cpp`, `project3.cpp`, `Project4(Most challenging).cpp`.

3D mode uses three.js from a CDN, so it needs an internet connection the first time; it falls back to the 2D scene otherwise.
